迷你四驱车
结构拆解

从“两节5号电池”到四轮同步驱动：把童年玩具拆成一套可讲、可演示、可参赛的工程系统。

定位：适合课堂汇报、科技节展示、童年玩具机械原理讲解。
01 · Design Goal

这不是“玩具介绍”，而是一次小型机械系统拆解

Module A

骨架系统

底盘决定零件安装位置、重心高度、抗扭强度，是整车的“承重平台”。

Module B

动力系统

两节AA电池向130直流马达供电，把电能转成高速旋转。

Module C

传动系统

齿轮组改变转速与扭矩，再通过轴把动力分配到前后轮。

Module D

稳定系统

导轮、轮胎、配重和车壳空气动力共同解决“快而不飞”的问题。

汇报核心：一辆四驱车 = 电路 + 马达 + 齿轮传动 + 车体稳定控制。
02 · Object Recognition

实物标注：这类车为什么叫“四驱车”？

前导轮
贴赛道墙，防止出轨
尾翼/车壳
外观 + 下压力 + 导流
前后轮
四轮同步参与驱动
后导轮
过弯稳定核心
1

不是靠遥控转向

迷你四驱车通常没有方向舵机，路线由赛道墙和导轮共同约束。

2

四驱的关键在传动轴

马达动力经过齿轮后同时送到前后轴，因此前后轮都能输出动力。

3

比赛本质是调校

同一辆车，换马达、齿轮、轮胎、导轮和配重，赛道表现会完全不同。

05 · Power Chain

动力链路：电池不是“直接推车”，而是驱动马达旋转

电能：AA电池供电
马达：电能→旋转
车轮：旋转→前进
环节作用汇报话术
电池提供电压与电流像“油箱+电泵”
马达输出高速旋转车的心脏
齿轮调节速度/扭矩车的变速箱
车轴传递动力到轮子车的传动轴
轮胎把旋转变成抓地前进最终落地执行
06 · Motor Anatomy

130直流马达：为什么一通电就转？

①

通电

电池通过金属触片把电流送入马达线圈。

②

成磁

线圈变成电磁铁，与马达外壳内的永久磁铁产生吸引/排斥。

③

换向

换向器让电流方向周期性切换，保证转子持续朝同一方向旋转。

④

输出

马达轴带动小齿轮，把高速旋转送进齿轮系统。

07 · Gear Ratio

齿轮比：为什么有的车起步猛，有的车直道快？

一句话讲清楚

齿轮像自行车变速：小齿带大齿更有劲，高速齿轮更快但更容易失控。

扭矩：起步/爬坡/过弯能力转速：直线极速摩擦：能量损耗
08 · Stability Control

跑得快不是本事，快且不飞才是调校能力

Roller

导轮

过弯时与赛道墙接触，把撞击摩擦变成滚动摩擦。导轮位置越合理，越不容易弹飞。

Center of Gravity

重心

重心越高，过坡和转弯越容易翻。配重的本质是把车压稳，而不是盲目加重。

Tire

轮胎

硬胎阻力小、直线快；软胎抓地强、过弯稳；海绵胎轻但耐久和抓地要看赛道。

展示语：四驱车调校的矛盾，是速度、抓地、稳定性三者之间的平衡。
09 · Tuning Strategy

改装不是越贵越强，而是按赛道反推配置

赛道类型目标推荐方向风险
长直道最高速度高速马达 + 小齿比 + 硬胎 + 低阻轴承过弯飞车、刹车不够
连续弯道稳定过弯大导轮 + 合理配重 + 中速齿轮 + 抓地轮胎直线速度损失
坡道/跳台落地不翻前后配重 + 制动海绵 + 降低重心车身变重、耗电快
综合赛道速度与稳定平衡中高速马达 + 中等齿比 + 前后导轮微调没有单项极致优势
参赛答辩点：改装思路要从“零件堆叠”升级为“赛道工况匹配”。
10 · Failure Diagnosis

常见问题诊断：看到现象，要能反推结构原因

飞车：速度超过稳定边界

  • 导轮位置太高或直径不合适
  • 前后配重不平衡，重心偏高
  • 马达太猛但制动不足

速度慢：能量损失过大

  • 齿轮啮合太紧，摩擦大
  • 轴承/车轴偏磨
  • 电池电量低或内阻大

打滑：轮胎抓地不足

  • 轮胎材质不适合赛道
  • 后轮压力不足
  • 起步扭矩过大

跑偏：左右阻力不对称

  • 车轴弯曲或轮毂安装不正
  • 左右导轮高度不同
  • 底盘轻微变形
11 · Presentation Script

一分钟汇报话术：让观众马上听懂

“这辆车看起来只是儿童玩具，但它其实包含完整的机械工程链路：电池供电，马达把电能变成旋转，齿轮负责调速增扭，传动轴把动力送到前后轮，导轮和轮胎负责稳定。它的核心不是简单跑得快，而是如何在不同赛道里，在速度、抓地力和稳定性之间做平衡。这也是它能成为很多人机械启蒙玩具的原因。”

讲结构

从系统架构切入，不陷入零件流水账。

讲原理

围绕能量转换、传动与稳定控制展开。

讲调校

把改装解释成工程决策，而不是堆配件。
