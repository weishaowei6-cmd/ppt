# 迷你四驱车结构拆解｜参赛级 HTML 汇报版

## 本地打开
直接双击 `index.html` 即可演示。

## 操作方式
- 键盘 `←` / `→` / 空格：翻页
- 右上角：全屏、导出 PDF
- 浏览器打印：建议选择横向、背景图形打开、边距无

## GitHub Pages 部署
1. 新建 GitHub 仓库
2. 上传本文件夹中的 `index.html` 和 `assets` 文件夹
3. 进入仓库 Settings → Pages
4. Source 选择 Deploy from branch
5. Branch 选择 main / root
6. 等待生成 Pages 链接
